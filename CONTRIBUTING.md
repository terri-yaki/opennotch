# Contributing

OpenNotch is a small macOS menu-bar app. Issues, discussions, and pull requests are open.

## Requirements

- macOS 14 (Sonoma) or later
- Xcode or the Command Line Tools

## Build

```bash
./build.sh
open build/OpenNotch.app
```

The app is ad-hoc signed. The first launch may need a right-click and Open.

## Pull requests

- Open a pull request against `main`.
- Say what changed and how you tested it.
- Keep the change focused. Match the style of the surrounding Swift.

## Bugs and questions

- Bug reports and feature requests go in [Issues](https://github.com/terri-yaki/opennotch/issues).
- Questions and ideas go in [Discussions](https://github.com/terri-yaki/opennotch/discussions).

Security reports do not belong in public issues. See [SECURITY.md](SECURITY.md).
